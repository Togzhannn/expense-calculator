# Expense Calculator

A small Python application for storing expenses and calculating totals.

## Features

- Add an expense with an amount and category.
- Calculate the total for a selected category.
- Calculate the total for all expenses.
- Reject invalid, non-positive, or Boolean amounts.

## How to run tests

```bash
python3 -m unittest -v
```

## Project structure

- `expense_calculator.py`: application logic.
- `test_expense_calculator.py`: automated tests.
- `AGENTS.md`: instructions and safety rules for AI coding agents.
